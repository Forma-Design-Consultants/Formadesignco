## Implemented flow and geometry

1. Explicit address search is the default, requesting at most five address candidates, filtering California by provider region metadata, and showing match/coordinate accuracy. Optional autocomplete is opt-in, disabled without readiness, debounced 900 ms and counted against the same 30-request daily quota; it sends typed text to Mapbox only when enabled. Its request contract is fixture-tested, not accepted as a live connection.
2. User selects an address; a signed, seven-day, account-bound ticket authorizes a 10-meter-radius Regrid lookup with limit five. User must select and visually confirm the parcel/APN. Nearby/stacked parcels are not automatically chosen.
3. Accepts valid closed single polygons (including one-part MultiPolygons) up to 128 vertices and 10–1,500-foot extents. Rejects missing, self-crossing, degenerate, holed and multipart geometry without inventing rectangles. Larger/complex properties require a later GIS workflow.
4. WGS84 boundaries become local east/south feet using Web Mercator scaled by cosine of anchor latitude. This is a local planning approximation, not a cadastral/survey projection. At 1,500 feet, latitude scale variation is small but nonzero; professional survey control remains required. Origin, scale, original WGS84 ring, provider ID/APN, retrieval/source dates and verification state are saved.
5. Exact selected architectural model is rotated/translated onto that coordinate frame. Both site views use the same footprint, wall solids, fixtures and transform. Aerial extent derives from actual rounded zoom and 800-pixel frame; the 3D ground image receives the same projection as the parcel. Map panning/zooming and terrain are not implemented; this is a fixed parcel-centered aerial with interactive building placement.
6. Distance checks use every actual polygon segment. Lot edges are numbered because frontage is not verified. User buffer is an assumption; no fake rectangular inset is drawn for irregular GIS parcels. Unmapped buildings/utilities/easements remain unknown.
7. Advanced manual correction accepts a WGS84 GeoJSON Polygon and source/reason. It validates and signs the correction, marks it `user-corrected`, retains original boundary/source and timestamp, and preserves world placement when within supported offset bounds. This is an import correction, not a vertex-dragging survey editor.
8. Save/reopen retains the signed sourced property and placement; real labels require a valid owner-bound provider ticket. Unsigned client-supplied 'verified' boundaries cannot be saved as provider geometry. Tickets expire after seven days; re-search is required for further saves after expiry. Signed ticket URLs are not provider API keys and require the same account to use.
9. Aerial is fetched same-origin once into browser memory per selected parcel; drag redraws reuse it. Provider errors keep the sourced polygon visible. The image can be hidden if misaligned. SVG export omits licensed aerial imagery; JSON export removes authentication tickets and image URLs but keeps geometry and provenance. No offline imagery distribution is implemented.
10. Persistent daily quota permits 30 provider requests per preview account (search, parcel and image combined), with 12-second timeouts and fixed hosts. Each successful parcel query can still bill up to five records. Provider-side monthly spend caps are additionally required. Quota contains only an owner/day counter, no address; prior days are purged on next lookup. Project/review records retain the existing seven-day expiry and owner deletion controls. Review handoff remains demo-only with no outbound writes.
