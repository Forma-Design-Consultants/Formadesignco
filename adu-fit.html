Look up the lot. Place the ADU.

Search a California address. The tool will load an available public parcel boundary, draw a preliminary buildable area, and let you drag and rotate an ADU over the aerial view.

1. Find the parcel

Enter the full street address. We’ll look for the property and request a parcel outline from an available public county source.

Address search © OpenStreetMap contributors.

2. Confirm the parcel border

The solid black outline is the public parcel geometry. Because GIS boundaries are approximate, compare it with the imagery before relying on the fit result.

Search an address to load the parcel.
Parcel not found? Align it manually

Drag the black handle and adjust these values to align the dashed fallback outline.

3. Set preliminary clearances

The green area applies an editable distance from every parcel edge. It does not identify the front yard or replace local zoning review.

4. Align the existing home

Drag the blue handle onto the existing home and adjust its approximate footprint. Aerial imagery does not provide a verified building outline.

5. Place the ADU

The tool chooses a starting position. Drag the green handle and rotate or resize the footprint to test the backyard.
