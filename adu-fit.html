Preliminary property visualization

See how an ADU may fit.

Search the property, align the lot and existing-home outlines, then drag an ADU around the backyard. Adjust every assumption so the visualization reflects what you know about the property.

1. Find the property

Enter the full California address. After the map moves, drag the black lot handle until the outline aligns with the visible property.

Address search © OpenStreetMap contributors.

2. Align the approximate lot

Use dimensions from a survey or property record when available. Rotation is clockwise. The edge marked “Street / front” controls the front setback.

3. Set preliminary clearances

These are editable planning assumptions—not verified rules. Enter the property’s known requirements or leave them for Forma to review.

4. Align the existing home

Drag the blue handle onto the existing house and adjust its approximate footprint. This can include attached projections if you increase the dimensions.

5. Place the ADU

Select a starting size or enter custom dimensions. Drag the green handle to move the ADU and use rotation to test different layouts.
